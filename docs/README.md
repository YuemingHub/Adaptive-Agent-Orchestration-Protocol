- `ROUTING_MODEL.md` — how routes transition and correct themselves as evidence changes.

- `INTEROPERABILITY.md` — host/runtime interoperability principles.
- `QUICKSTART.md` — installation and first-use guidance.

The intended conceptual order is:

```text
Developer situation
→ route
→ project/outcome understanding
→ capability plan
→ progressive integration only if needed
→ execution
→ verification
```
